# Small CSV and file automation services

The free Fileworks CLI is MIT licensed. Paid work adapts a small file workflow to
written customer-specific rules; buying a service is not required to use the CLI.

| Service | USD | Scope after review |
| --- | ---: | --- |
| CSV cleanup | 49 | One UTF-8 CSV up to 10,000 rows, one agreed ruleset, output + change report, one revision against agreed rules. |
| Reusable CSV fixer | 99 | One CSV input, one output format, a Python script implementing agreed rules, sanitized tests, run instructions, one revision. |
| One file workflow | 149 | One local CSV/JSON workflow, up to three agreed transformations, validation/error handling, source/tests/docs, one revision. |

Request a scope check using this repository's **Issues → New issue → Request a
service scope check**. Issues are public: describe the workflow and use made-up
examples. Do not post private files, customer data, credentials, or financial
information. No private-data transfer channel is currently provided here.

Before work is booked, the deliverable, delivery estimate, price, revision boundary,
customer acceptance checks, and supported payment method must be confirmed in
writing. This repository does not collect payments. Payment onboarding is pending;
do not send unsolicited payments. Marketplace-originated jobs stay inside their
marketplace's messaging, contracting, and payment process.

XLSX workbooks, cloud APIs/accounts, deployments, sensitive/regulated datasets, and
larger jobs need separate scope review. No benchmark, customer count, financial
result, or delivery deadline is promised without evidence and an accepted scope.

Synthetic demonstrations in `examples/` show the free tool's actual behavior.
They are not customer work or testimonials.
