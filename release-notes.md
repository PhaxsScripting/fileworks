Fileworks 0.1.0 is an original, standard-library local CSV audit and explicit cleanup utility.

- UTF-8/BOM and comma/semicolon/tab/pipe support, bounded inputs, JSON/Markdown audits.
- Explicit whitespace, blank-record, exact-duplicate, and formula-escaping flags.
- Preserve source files and string IDs; atomic new output with no overwrite.
- Synthetic before/after data, documentation, MIT license, 14 local regression tests.
- Fixed-scope customer-specific automation offer; scope inquiries use synthetic public examples. Payment onboarding remains pending.

Delimiter and spreadsheet-formula checks are heuristics. No spreadsheet/customer-file acceptance or revenue is claimed. Run `python3 -m fileworks --help` from the source checkout.
